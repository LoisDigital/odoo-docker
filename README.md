# Odoo Docker

This repo allows to quickly create Odoo development environments using Docker.

This repo originally was a fork from https://github.com/junariltd/junari-odoo-docker.

## Pushing to Docker Hub

To push to Docker Hub, use the command line (not Docker Desktop, it doesn't work). The repo
on Docker Hub is called "odoo-docker" (https://hub.docker.com/repository/docker/loistal/odoo-docker).
